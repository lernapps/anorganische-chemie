Reading the periodic table

On this page

Why

There are over a hundred elements. The periodic table orders them so that elements with similar properties stand below each other. If you can read it, you quickly find the most important facts about any element.

Rule

Element symbol

The element symbol is the abbreviation of an element with one or two letters, for example C for carbon.

Period

A period is a row in the periodic table. The number of the period tells how many shells an atom has.

Group

A group is a column in the periodic table. Elements in one group have similar properties.

The elements are ordered by increasing atomic number, in every row from left to right. After every noble gas a new row begins.

Example

Carbon in the periodic table

The symbol is C, the atomic number 6. Carbon is in period 2, because its atoms have two shells. It is in group 14.

Exercise

Three worked tasks, each with its solution:

  1. Task no. 1

    What is the atomic number of Oxygen (symbol O)?

    Hint

    Look for the symbol O in the table. The number in brackets is the atomic number.

    Solution
    1. Oxygen has the atomic number 8.

    Right answer: 8

Exercise

Three worked tasks, each with its solution:

  1. Task no. 1

    In which period is Sodium? The electrons of Sodium sit on shells with 2, 8, 1 electrons.

    Hint

    The period is the number of shells. Count the numbers in the list.

    Solution
    1. Sodium has 3 shells, so it is in period 3.

    Right answer: 3

  2. Task no. 2

    In which period is Bismuth? The electrons of Bismuth sit on shells with 2, 8, 18, 32, 18, 5 electrons.

    Hint

    The period is the number of shells. Count the numbers in the list.

    Solution
    1. Bismuth has 6 shells, so it is in period 6.

    Right answer: 6

  3. Task no. 3

    In which period is Helium? The electrons of Helium sit on shells with 2 electrons.

    Hint

    The period is the number of shells. Count the numbers in the list.

    Solution
    1. Helium has 1 shells, so it is in period 1.

    Right answer: 1
